# Деды 🕯️

Поминальная ночь. Party-игра для компании от 2 до 20 человек: общий экран (ТВ или ноутбук) и телефоны игроков.

Раз в году умершие возвращаются к родному столу. Угодишь — благословят род. Не угодишь — уведут с собой. Говорить они не могут. Только стучать.

## Как запустить

```bash
npm install
npm start
```

1. На компьютере, подключённом к ТВ, откройте `http://localhost:3000/host`.
2. Игроки сканируют QR-код с экрана (телефоны должны быть в той же Wi‑Fi сети) и вводят имя.
3. Включите звук кнопкой на экране — стук идёт из колонок ТВ.
4. «Зажечь свечи» — и ночь началась.

Чтобы играть через интернет, разверните сервер (Render, Railway, VPS) и задайте `PUBLIC_URL` — по этому адресу будут вести QR-коды.

| Переменная | Что делает |
| --- | --- |
| `PORT` | Порт сервера, по умолчанию `3000` |
| `PUBLIC_URL` | Внешний адрес для QR-кода |
| `FAST=1` | Короткие таймеры для проверки (`npm run dev`) |

## Правила

**Роли.** Примерно каждый четвёртый игрок становится **предком**, остальные — **живые**. С 8 игроков один из предков тайно оказывается **заложным покойником**: он умер нехорошей смертью и хочет, чтобы Род погас.

**Один час ночи:**

1. **Предки пришли.** На стол выкладываются угощения и обряды. Предки на своих телефонах видят, чего хотят: одно угощение и один обряд.
2. **Спрашивайте (2 минуты).** Живые задают вопросы вслух. Предки молчат и отвечают только кнопками: **тук** — да, **тук-тук** — нет. Стук звучит на ТВ, а у живых вибрирует телефон. Ещё предок может прошептать пару слов из случайного набора («холод», «пчела», «отражение»…). Стуки и слова ограничены.
3. **Накрывайте стол (30 секунд).** Каждый живой тайно выбирает угощение и обряд. Ставится то, за что проголосовало большинство.
4. **Приговор:**
   - угадали и то и другое — **кричит петух** 🐓;
   - угадали наполовину — **гаснет свеча** 🕯️;
   - не угадали ничего — гаснет свеча, и предок **уводит одного из живых** (того, кто угадал хуже всех). Уведённый становится предком и продолжает играть.

С каждым часом на столе всё больше вариантов.

**Победа.** Три петуха — рассвет, Род спасён. Погасли все четыре свечи или не осталось живых — вечная ночь, побеждает заложный.

**Заложный** знает настоящее желание и стучит так, чтобы запутать живых. После каждого вскрытия видно, кто что стучал, — так его и вычисляют.

Опоздавшие могут войти посреди ночи — они сразу становятся предками.

## Разработка

```bash
npm run dev   # короткие таймеры, перезапуск при изменениях
npm test      # логика игры + полный прогон ночи через сокеты
```

- `src/game.js` — правила и состояние комнаты (без сети, легко тестировать)
- `src/server.js` — Express + Socket.IO, комнаты, переподключение
- `src/content.js` — угощения, обряды, слова предков
- `public/host.*` — общий экран, `public/player.js` — телефон, `public/sound.js` — синтезированные звуки
